### 2. High-Speed Interconnect Readiness (CDC & Async FIFOs)
- **Objective:** Establish the architectural foundation necessary to verify high-speed and Die-to-Die (D2D) interconnects like **UCIe/PCIe**.
- **Highlights:**
  - Design and Verification of a robust **Asynchronous FIFO** to handle data transfer between separate clock domains.
  - Implementation of **Gray-code pointers** to prevent metastability.
  - Directed and constrained-random testing for FIFO Full/Empty corner cases.
